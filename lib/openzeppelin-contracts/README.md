# Vendored OpenZeppelin Contracts

This directory contains the ERC-20 dependency closure from
[OpenZeppelin Contracts v5.1.0](https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.1.0).
Only the five required Solidity files and the upstream MIT license are included.
The Solidity source is unmodified. This is an ordinary source directory, not a
submodule; builds do not download dependencies.

`SHA256SUMS` records the downloaded files. From this directory, verify them with
`sha256sum -c SHA256SUMS`.
